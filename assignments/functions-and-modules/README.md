# 📘 Assignment: Functions and Modules

## 🎯 Objective

Learn how to organize Python programs using functions, parameters, return values, and modules for reusable code.

## 📝 Tasks

### 🛠️ Write Reusable Functions

#### Description
Create functions that perform simple operations and return results instead of printing directly.

#### Requirements
Completed program should:

- Define a function `greet_user(name)` that returns a greeting string.
- Define a function `calculate_area(width, height)` that returns the area of a rectangle.
- Demonstrate both functions with example calls and print their returned values.


### 🛠️ Use Function Arguments and Return Values

#### Description
Create a function that accepts user input, processes it, and returns a result.

#### Requirements
Completed program should:

- Define a function `get_birth_year(current_year, age)` that returns the birth year.
- Ask the user for the current year and their age.
- Print the returned birth year in a complete sentence, e.g. `You were born in 2008.`


### 🛠️ Split Code into a Module

#### Description
Move reusable functions into a separate Python module and import them into the main program.

#### Requirements
Completed program should:

- Create a new file `module_utils.py` with at least two functions used above.
- Import the module from `main.py`.
- Call the imported functions from `main.py` and print their results.
- Keep the module focused on reusable helper functions only.
